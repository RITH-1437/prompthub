# 🚀 PromptHub

**PromptHub** is a modern, community-driven platform built with Laravel for discovering, sharing, and collaborating on high-quality AI prompts (ChatGPT, Midjourney, Claude, etc.). 

Featuring a stunning dark, glassmorphic UI, PromptHub makes it easy to organize your prompt engineering workflow and connect with other creators.

## ✨ Features

### 👨‍💻 For Creators
- **Prompt Management:** Create, edit, and organize your AI prompts with syntax highlighting and 1-click copy buttons.
- **Collections:** Group your prompts into custom collections for different workflows (e.g., Coding, Marketing, Design).
- **Favorites:** Save your favorite prompts from other creators for quick access.
- **Personal Profiles:** Customizable user profiles with avatar uploads and social follow systems.
- **Achievements:** Gamified achievement system (e.g., "First Prompt", "Prompt Master") based on user activity.

### 🌐 Community & Discovery
- **Explore & Trending:** Discover new prompts through search, trending algorithms, and top-rated charts.
- **Leaderboard:** Compete with other creators! Rank is determined by prompt views, copies, and engagement scores.
- **Ratings & Comments:** Rate prompts (1-5 stars) and leave comments to discuss prompt strategies.
- **Notifications:** Track activity with database notifications for follows, comments, and other interactions.

### 🤖 AI Integration
- **AI Prompt Generator:** Describe what you need, and the integrated AI will craft the perfect advanced prompt for you.
- **Floating AI Assistant:** A globally accessible AI chat bubble to help you refine and brainstorm prompts on the fly.
- Powered by the **OpenRouter API** (utilizing Google Gemini Flash-Lite).

### 🛡️ Admin Dashboard
- Comprehensive metrics, analytics, and real-time activity feeds.
- User role management and moderation tools.
- Ability to "Feature" high-quality prompts to showcase them on the platform.

## 🛠️ Tech Stack

- **Backend:** Laravel 11 (PHP 8.2+)
- **Frontend:** Blade Templates, Tailwind CSS (v4), Vanilla JS
- **Icons:** Lucide Icons
- **Database:** MySQL / SQLite
- **AI API:** OpenRouter

## 🚀 Installation & Setup

Follow these steps to get a local copy of PromptHub up and running.

### Prerequisites
- PHP >= 8.2
- Composer
- Node.js & NPM
- MySQL or SQLite
- OpenRouter API Key (for AI features)

### 1. Clone the repository and install dependencies
```bash
git clone https://github.com/yourusername/prompthub.git
cd prompthub
composer install
npm install
```
